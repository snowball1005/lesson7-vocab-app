휴대폰에서 '앱처럼 설치'하려면 이 폴더를 HTTPS 정적 호스팅에 올려야 합니다.
Android(Chrome): 사이트 접속 → 메뉴 → 앱 설치/홈 화면에 추가
iPhone(Safari): 공유 버튼 → 홈 화면에 추가

기능
- 하루 5단어 × 5일
- 영어→뜻 / 뜻→영어 / 예문 빈칸
- 발음 듣기
- 틀린 단어 자동 누적 복습
- 학습 완료/별 점수 기기 저장
- 설치 후 오프라인 사용 가능
