# 영어·과학 앱 휴대폰 설치 및 오프라인 점검표

이 점검표는 PR 병합 및 배포 완료 후 실제 서비스 주소에서 실행합니다. GitHub 파일 보기 주소는 설치 주소가 아닙니다.

- 점검일: __________ / 기기·OS: __________ / 브라우저: __________
- 배포 주소: __________ / 배포 커밋: __________
- 영어: 서비스 루트 `/` / 과학: 같은 서비스의 `/science/`
- 각 항목에 □ 통과 / □ 실패 / □ 해당 없음 표시와 재현 내용을 남깁니다.
- 오프라인 저장은 앱을 온라인으로 한 번 열고 서비스워커 설치가 완료된 후 사용할 수 있습니다. 발음은 기기의 음성·네트워크 지원에 따라 별도로 점검합니다.

## 3. 영어 오답·채점·기록 이전

| 확인 | 통과 기준 | 결과 |
|---|---|---|
| 기존 객관식 오답 | 업데이트 후 이전 오답이 같은 단어·방향으로 출제 | □ |
| 기존 기록 유지 | 정답으로 오답 횟수를 줄인 뒤 앱을 닫아 다시 열어도 감소 상태 유지 | □ |
| 철자 오답 저장 | 철자 문제에서 일부러 틀림 → 홈 오답만 → 같은 단어를 직접 입력하는 문제로 표시 | □ |
| 철자 정답 처리 | 복습에서 정답 입력 → 해당 오답 횟수 1 감소, 0이면 복습 대상에서 제외 | □ |
| 연속 확인 | 정답을 넣고 확인을 여러 번 눌러도 점수 1회·별 2개만 증가 | □ |
| Enter 확인 | 철자를 입력하고 Enter → 한 번만 채점 | □ |
| 빠른 단원 전환 | 정답 선택 직후 Lesson 8 클릭 → 1초 후에도 Lesson 8 홈 유지 | □ |
| 빠른 홈 전환 | 철자 확인 직후 그만하기 → 홈 화면 유지 | □ |
| 통계·별 유지 | 재실행 후 별·레벨·오답 기록 유지, Lesson 7·8 기록 분리 | □ |

오답 수는 남은 오답 문제 ID 수입니다. 같은 문제를 여러 번 틀렸다면 한 번 맞혀도 오답에 남을 수 있습니다. 이전 버전은 철자 오답을 저장하지 않았으므로 이미 유실된 철자 기록은 복원할 수 없습니다.

## 4. 비행기 모드에서 두 앱 교차 점검

먼저 온라인에서 영어와 과학을 각각 열고, 각 앱을 한 번 새로고침해 둡니다. 그다음 비행기 모드를 켜고 Wi-Fi도 끕니다.

| 확인 | 통과 기준 | 결과 |
|---|---|---|
| 영어 재실행·새로고침 | 홈·목록·Lesson 전환·문제 풀이 모두 동작 | □ |
| 과학 재실행·새로고침 | 단원·개념·카드 정답·문제·누적 복습 동작 | □ |
| 영어 → 과학 교차 실행 | 과학 앱이 영어 화면으로 바뀌지 않고 정상 실행 | □ |
| 오프라인 기록 저장 | 두 앱에서 풀이 후 닫고 다시 열어 기록 유지 | □ |
| 온라인 복귀 | 새 기록이 유지되고 정상 새로고침 가능 | □ |
| 다음 업데이트 후 과학 | 영어 SW 업데이트 뒤에도 과학을 다시 오프라인으로 열 수 있음 | □ |

‘다음 업데이트 후 과학’ 항목은 후속 SW 버전 배포 때 추가 확인합니다. 최초 `/science/` 방문을 오프라인에서 시도하는 것은 지원 범위가 아닙니다.
